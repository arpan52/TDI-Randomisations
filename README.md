# PLT-Randomisation-Analysis
This repository contains the R source code for all simulation studies conducted in the paper  
**_Randomisation Strategies and Analysis for Complex-Intervention Trials with Dynamic Therapist Constraints_**.

The paper provides the methodological foundation for the randomisation strategies used in practitioner-led intervention trials. It proposes three novel randomisation methods that explicitly account for practical constraints faced by practitioners, including therapist capacity, availability, and turnover.

These methods are compared with existing randomisation strategies in terms of:
- **Operational efficiency**, measured by time to target recruitment, and  
- **Statistical efficiency**, evaluated through the precision of inference obtained from the subsequent analysis.

All scripts required to reproduce the simulation results and figures presented in the paper are included in this repository.
